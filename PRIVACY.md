Privacy Policy

Last updated: 2026.07.28

This Privacy Policy explains how the DotaQuiz bot collects, uses, and protects information when you use it on Discord.

1. Information We Collect and Use

When you use the DotaQuiz bot, the following identificators are saved:

Discord User ID — to save user progress such as gold accumulated and upgrade items.
Discord Server (Guild) ID — to ensure the bot's quiz questions do not repeat too soon, too often.

2. Data Storage & Security

Data is stored in a local Sqlite3 database. The data is secure and is only ever used by the bot itself, it is never transferred. However, no method of storage is 100% secure, so flawless security cannot be guaranteed.

3. Data Retention & Deletion

The Discord user identificator is stored indefinitely, however if a user wishes to clear their user id and all their saved progress they can easily do so with the "clearstats" command at any time.
The Discord guild identificator is stored as long as the bot is within the guild. When the DotaQuiz bot is removed from a guild, the guild ID is cleared from the database.

4. Changes to This Policy

Though it is very unlikely, this policy may be updated some time in the future. Continued use of the DotaQuiz bot after changes constitutes acceptance of the revised policy.

5. Contact

If there are any concerns with this policy please feel free to contact us via our Discord server: https://discord.gg/brYr5kvUnA
